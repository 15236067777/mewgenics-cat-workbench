# Local data and bug reports

Do not post saves, generated `catalog.json`, `settings.json`, backups, exported
diaries, or screenshots containing information you do not want public.

The tool normally performs local file operations. The first-run launcher downloads
Python dependencies from PyPI. No telemetry or automatic save uploads are included.

Save editing must be performed while Mewgenics and the original Save Editor are
closed. Keep an independent save backup when trying a new game/editor version.

For bugs, report the application, game and editor versions, an error message and
reproduction steps. Supply a minimized synthetic example when possible.
